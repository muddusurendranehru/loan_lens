========================================
TROUBLESHOOTING 404 ERRORS
========================================

If you see 404:
1. Make sure server is running:
   Check: netstat -ano | findstr :3001

2. Use EXACT URLs above (no trailing slashes)

3. Server must be started with:
   cd C:\Users\MYPC\Desktop\loan_lens
   npm run dev

4. Wait 10-15 seconds after starting server

5. Clear browser cache (Ctrl+F5)
