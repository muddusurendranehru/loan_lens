========================================
PUSH TO GITHUB - PowerShell Commands
========================================

⚠️  IMPORTANT: PowerShell uses ; NOT && for chaining commands!

========================================
OPTION 1: Use the Script (Easiest)
========================================

Just run:
.\PUSH_TO_GITHUB.ps1

This does everything automatically.

========================================
OPTION 2: Manual Commands (One by One)
========================================

# 1. Navigate to project
cd C:\Users\MYPC\Desktop\loan_lens

# 2. Check status
git status

# 3. Add all files
git add .

# 4. Commit
git commit -m "Update LoanLens: HOMA Clinic EBITDA Tracker"

# 5. Push
git push -u origin main

========================================
OPTION 3: One-Line (PowerShell Safe)
========================================

cd C:\Users\MYPC\Desktop\loan_lens; git add .; git commit -m "Update LoanLens"; git push -u origin main

========================================
IF AUTHENTICATION FAILS
========================================

You may need to set up GitHub authentication:

1. Set your name:
   git config --global user.name "Your Name"

2. Set your email:
   git config --global user.email "your@email.com"

3. For HTTPS push, you'll need a Personal Access Token:
   - Go to: https://github.com/settings/tokens
   - Generate new token (classic)
   - Use token as password when pushing

OR use SSH instead:
   git remote set-url origin git@github.com:muddusurendranehru/loan_lens.git

========================================
COMMON POWERShell ERRORS FIXED
========================================

❌ WRONG (PowerShell doesn't support &&):
   git add . && git commit -m "msg" && git push

✅ CORRECT (Use ; instead):
   git add .; git commit -m "msg"; git push
