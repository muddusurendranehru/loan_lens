========================================
GIT CLONE & SETUP COMMANDS
========================================

# Step 1: Clone Repository
git clone https://github.com/muddusurendranehru/loan_lens.git
cd loan_lens

# Step 2: Install Dependencies
npm install

# Step 3: Create .env.local
# Copy your DATABASE_URL and NEXTAUTH_SECRET from Neon Console

# Step 4: Start Server
npm run dev

# Step 5: Open Browser
# http://localhost:3000
