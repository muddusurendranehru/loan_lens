========================================
QUICK FIX FOR PRODUCTION ERROR
========================================

ERROR: "null value in column 'phone' violates not-null constraint"

ROOT CAUSE: Production database has phone column as NOT NULL,
but your code doesn't insert phone (only email and password).

========================================
SOLUTION (Choose One)
========================================

OPTION 1: Make Phone Optional (Recommended - 30 seconds)
----------------------------------------------------------
1. Go to Neon Console: https://console.neon.tech
2. Select your project → SQL Editor
3. Run this SQL:

   ALTER TABLE users ALTER COLUMN phone DROP NOT NULL;

4. Done! Test signup again.

OPTION 2: Remove Phone Column (If you don't need it)
----------------------------------------------------
1. Go to Neon Console → SQL Editor
2. Run this SQL:

   ALTER TABLE users DROP COLUMN IF EXISTS phone;

3. Done! But phone data will be lost.

========================================
VERIFY THE FIX
========================================

After running the SQL, verify in Neon Console:

SELECT column_name, is_nullable 
FROM information_schema.columns 
WHERE table_name = 'users' AND column_name = 'phone';

Expected: is_nullable = 'YES' (or column doesn't exist)
