========================================
IF YOU GET ERRORS
========================================

Error: "Port 3000 is in use"
Fix:
cd C:\Users\MYPC\Desktop\loan_lens
Stop-Process -Name node -Force
npm run dev

Error: "Missing script: dev"
Fix:
cd C:\Users\MYPC\Desktop\loan_lens
npm install
npm run dev

Error: "Unable to acquire lock"
Fix:
cd C:\Users\MYPC\Desktop\loan_lens
Remove-Item .next\dev\lock -Force -ErrorAction SilentlyContinue
Stop-Process -Name node -Force
npm run dev
